Interpolación polinomial de Newton

Introduce puntos con valores de x distintos. El programa construye la tabla de diferencias divididas, obtiene el polinomio interpolante y permite evaluarlo sin instalar programas ni conectarse a internet.

1. Ingresa los puntos

Usa punto decimal. Puedes separar x e y con coma, punto y coma, espacio o tabulación. Se admiten nodos no equidistantes y notación científica, por ejemplo: 1e-3, 2.5.

3. Tabla de diferencias divididas

Los valores destacados de la primera fila son los coeficientes de Newton. Los guiones indican posiciones que no se requieren.

4. Evalúa el polinomio

¿Cómo funciona?

  1. Se asigna f[xᵢ] = yᵢ a la primera columna.
  2. Para cada orden j se aplica:
    f[xᵢ, …, xᵢ₊ⱼ] = (f[xᵢ₊₁, …, xᵢ₊ⱼ] − f[xᵢ, …, xᵢ₊ⱼ₋₁]) / (xᵢ₊ⱼ − xᵢ)
  3. Se toman los coeficientes aⱼ = f[x₀, …, xⱼ] y se construye:
    P(x) = a₀ + a₁(x − x₀) + a₂(x − x₀)(x − x₁) + …
  4. Se evalúa mediante multiplicación anidada, evitando desarrollar el polinomio para calcular un valor.

Con n puntos distintos existe un único polinomio de grado a lo sumo n − 1 que pasa por todos ellos. El grado puede ser menor. No se necesita que los valores de x estén igualmente espaciados.

JavaScript · cálculo local · aritmética de doble precisión. Los grados elevados, nodos muy cercanos o valores extremos pueden producir errores numéricos. La extrapolación se identifica y debe interpretarse con precaución.
